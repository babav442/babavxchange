BABAVXchange prototype v0.1

CONTENTS
- index.html: responsive web app prototype
- manifest.webmanifest and sw.js: basic PWA install/offline shell

TRY IT
1. Open index.html in a modern browser, or host this folder on an HTTPS static host.
2. On Android Chrome, open the hosted site and use the browser menu > Install app / Add to Home screen.
3. Use only fake/test card details. Demo records and rates are stored locally in that browser.

IMPORTANT
This is a front-end prototype, not a live financial service. It does not:
- create real user accounts or securely authenticate admins;
- verify gift card balances/codes with issuers;
- receive or send bank transfers;
- hold customer funds or make payouts;
- securely store sensitive data or synchronize across devices.

Before launch, connect a secure backend/database, identity and admin access controls,
gift-card verification provider/workflow, bank transfer/payment provider, audit logs,
fraud controls, privacy policy, terms, and applicable Nigerian regulatory/legal review.
Never collect real gift card codes in this prototype.
